# RP2350 datasheet

`rp2350.txt` is the text of the *RP2350 Datasheet* by Raspberry Pi Ltd, Release 8 (build date 01/10/2026, build version 80d627281ed5), downloaded from https://datasheets.raspberrypi.com/rp2350/rp2350-datasheet.pdf.

It is unmodified apart from the conversion from PDF to plain text, which also inserted a `=====PAGE n` line at the start of each PDF page.

`difftest/src/cases.rs` quotes it, and a test checks that every quote appears in this file.
